# The Procurement Atlas — Procurement Fundamentals

A system-agnostic procurement learning prototype (Phase 1.1) built with Next.js, React, TypeScript and Tailwind CSS. It covers foundational procurement concepts, interactive process journey, stakeholder responsibilities, healthcare/retail/manufacturing scenarios, Stonebridge Manufacturing capstone, searchable glossary, 16-question mastery assessment, and browser-local progress tracking.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000, then run `npm run build` for production validation.

## Current status

Source prototype only. Not yet deployed or verified by a successful production build. Scenarios and supplier quotations are fictional; practices vary by organization, jurisdiction and purchasing category. No brand- or ERP-specific training is required.
